🧭 Si lidhet në Power BI Desktop (falas)
  1. Hapni Power BI Desktop → Get data (Merr të dhëna) → Web.
  2. Ngjitni lidhjen e një tabele (p.sh. antaresia) → OK → zgjidhni Anonymous → Connect.
  3. Në dritaren që hapet: Transform Data → kontrolloni që rreshti i parë të jetë koka ("Use first row as headers") → Close & Apply.
  4. Përsëriteni për tabelat e tjera (shtepite, fondi, harxhimet…).
  5. Te Model view lidhni tabelat me kolonën nr_shtepise (shtepite → antaresia / varrezat / fondi) dhe pagesa_id (antaresia → antaresia_vitet).
  6. Për të dhëna të reja: butoni Refresh në Power BI.

Nëse shumat dalin gabim (p.sh. 12.5 lexohet 125): File → Options → Regional settings → "English (United States)". Shumat janë me pikë dhjetore; datat në formatin 2026-11-27. Kolonat shuma_eur janë gjithçka e kthyer në € me kursin blerës.

Alternativë pa Power BI: te 💾 Backup → "Excel i plotë", ose hapni lidhjen në Excel (Data → From Web).
