📱 Hapi 1 — Në telefonin Android të xhamisë
  1. Hapni Google Play dhe instaloni "SMS Gateway for Android" (ose shkarkojeni nga sms-gate.app).
  2. Hapeni aplikacionin dhe klikoni Allow / Lejo për SMS.
  3. Aktivizoni çelësin Cloud server, pastaj çelësin kryesor lart (Offline → Online).
  4. Te seksioni Cloud Server shfaqen Username dhe Password — shkruajini më poshtë te Hapi 2.
  5. Te Settings → Apps → SMS Gateway → Battery zgjidhni Unrestricted / Pa kufizime, që të mos fiket.
